Found the right color? Save it as a token right there. Paper now lets you add a color token from any color property panel: fill, border, shadow, wherever you set a color.

Why it helps: tokens used to mean a trip to a separate setup step or asking your agent to create them over MCP. Now the habit is simple. Tune a color, make it a token, keep going.

A good workflow:

1. Explore colors freely on one frame.
2. When one sticks, add it as a token from that panel.
3. Name it for its role (`surface`, `accent`), not its hue. The September drop also added token name placeholders and truncates long names, so short role names read best.

Tokens still travel between files via File menu, Theme, Copy theme / Paste theme.
