You can now copy a selection as **React CSS**, **Tailwind**, or a **PNG** straight from the export panel. The right-click menu still works too.

Why bother: when you are already in the export panel setting scale or format, the copy is right there. No context switch back to the canvas.

Quick picks:

- **React CSS or Tailwind** when you are pasting into a codebase or handing a component to an agent.
- **PNG** when you need a quick image for Slack, a doc, or a ticket.

Prefer the keyboard? The build log lists &#8997; R for Copy as React CSS and &#8997; T for Copy as Tailwind.

Tip: code comes out cleaner from frames built with flex layout. Wrap loose elements before you copy.
